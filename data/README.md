# data フォルダ

年度ごとの「職種・職位別にどのコンピテンシー項目が割り当てられているか」を置く場所。

    data/assignments.local.js

このファイルは社内の方針が読み取れる内容のため、`.gitignore`（`*.local.js`）で
除外しており、このリポジトリには含まれていない。

ファイルが無い場合、アプリは「所属・職位」の選択欄を出さず、
コンピテンシー83項目の一覧から自分で選ぶ形で動く。診断そのものは問題なく行える。

## 作り方

社内のコンピテンシー一覧（xlsx）を用意して、次を実行する。

    python tools/generate-data.py "2026年度 コンピテンシー一覧.xlsx"

`src/competencies.js`（83項目の名称と定義。公開してよい内容）と、
`data/assignments.local.js`（手元限定）の2つが作られる。
年度が変わったら、新しいxlsxを指定して再実行すればよい。
