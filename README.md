# competency-navi（コンピテンシー目標ナビ）

社員がコンピテンシー（行動目標）を立てるときに、より具体的で実行可能な目標に
仕上げられるよう支援する社内ツール。

グリーンライフ産業株式会社の社内利用を前提とした非公開リポジトリ。

## 状態

仕様検討中。実装はこれから。

## 開発方針

社内ルールに従い、専用サーバーが不要な構成を優先する。

1. Google Apps Script（GAS）Web アプリ ＜第一候補＞
2. AppSheet
3. Looker Studio

サーバーへのデプロイが必要になった場合は、独断で進めず上長に相談する。

## 取り扱い注意

- 人事評価に関わる内容を扱うため、リポジトリは **Private** で運用する
- 個人名・評価内容を含む実データはコミットしない（`_private/` に置く。`.gitignore` 済み）
- API キー・Webhook URL 等の認証情報はコミットしない
