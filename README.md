# competency-navi（コンピテンシー目標ナビ）

社員がコンピテンシー（行動目標）を立てるときに、より具体的で実行可能な目標に
仕上げられるよう支援する社内ツール。

グリーンライフ産業株式会社の社内利用を想定した学習課題として開発している。
第三者によるレビューを受けるため、リポジトリは公開（Public）で運用する。

## 状態

仕様検討中。実装はこれから。

## 開発方針

社内ルールに従い、専用サーバーが不要な構成を優先する。

1. Google Apps Script（GAS）Web アプリ ＜第一候補＞
2. AppSheet
3. Looker Studio

サーバーへのデプロイが必要になった場合は、独断で進めず上長に相談する。

## 取り扱い注意

公開リポジトリのため、以下は絶対にコミットしない。

- 実在する社員の氏名・評価内容・目標文などの実データ
- 社内の評価制度そのものが特定できる詳細な項目表
- API キー・Webhook URL・パスワード等の認証情報

動作確認やデモに使うデータは、すべて架空のサンプルを用意する。
実データが必要な場合は `_private/` に置く（`.gitignore` 済みで追跡されない）。
